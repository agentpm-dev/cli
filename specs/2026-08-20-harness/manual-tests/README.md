# Harness Manual Test Runbooks

These runbooks preserve the manual verification history for the Harness spec.
They were moved here from the `agentpm` repo root after the Harness release-band
work stabilized.

Unless a runbook says otherwise, run commands from the `agentpm` repo root. The
generated fixture directories such as `harness-m19-test/`, `harness-m20a-test/`,
and `harness-release-verify-test/` intentionally still live at the repo root.
