Composition panel

One node per kind, expandable

The fan stays the composition story: an Agent Package made of Skills, Tools, Knowledge, Memory, Profiles and a Loop. Each node represents a kind, not a package, so the shape of the graph is constant whether a package has one Tool or thirty. A +N badge says there is more inside; expanding reveals it without changing the shape. All three packages below are real.

No Loop

Conformant APDS, and not runnable by Harness — a Loop is required by this Runner, not by the standard. ↳ marks a version resolved from agent.lock rather than pinned in the manifest.

Why one node per kind

  • The shape is the story. "An Agent Package composes Skills, Tools, Knowledge, Memory, Profiles and a Loop" is the positioning claim. A node per package buries that under package names as soon as a graph gets wide.
  • The graph stops growing. Six nodes at most, whatever the package contains. A 30-Tool package renders at the same size as a 1-Tool package.
  • Absent kinds vanish. ops-console has no Knowledge, so there is no Knowledge node — not a ghosted one, not a zero.
  • Loop carries no badge. It is a single binding in the manifest, not an array, so it can never have a +N. The UI shape matches the data shape.
  • Inherited stays separate. Transitive dependencies group under the parent that pulled them in, which is the only thing that makes the edge meaningful once there is more than one.

Still open

  • Which package is the visible one? Currently manifest order, so the author's first entry wins. Alphabetical is more predictable but discards authored intent.
  • Very large groups. +7 expands to a readable list; +40 would not. A cap inside the expansion with a link to a full view is probably needed.
  • Does the badge read as "expandable"? The chevron is inside the count pill. An always-visible affordance may be clearer than one that only appears when N > 1.
  • Deep links. Expansion is local state. If Composition is ever linked to from elsewhere, a specific package may need to open expanded and scrolled.
