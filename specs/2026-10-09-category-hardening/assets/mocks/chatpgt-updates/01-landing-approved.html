Build AI agents the way software is supposed to be built.

AgentPM is the package manager for AI agents. Agents are hard to reuse when their tools, instructions, knowledge and workflows are scattered across project code. AgentPM brings those pieces together as versioned Agent Packages you can share, install and run.

Install the CLI
$ brew tap agentpm-dev/tap brew install agentpm
Browse packages → Read the docs → · Free to use. No account needed to install.

Run supported Agent Packages with the AgentPM Harness, or integrate reusable Components through the Node and Python SDKs. APDS does not tie the definition to one Runner.

Agent Package Management

Agents are software. Treat them like it.

An Agent Package defines the complete system through its Components, bindings and workflow. Version it, share it and reuse it instead of rebuilding it in every project.

agent.json (excerpt) @zack/devwork-copilot 
{
  "standard": { "id": "agentpm", "version": "1.0.0" },
  "kind": "agent",
  "version": "0.1.10",

  "tools":     [{ "name": "@zack/summarize-text",          "version": "0.1.10" }],
  "skills":    [{ "name": "@zack/issue-triage-playbook",   "version": "0.1.1"  }],
  "knowledge": [{ "name": "@zack/devwork-maintainer-guide", "version": "0.1.0"  }],
  "memory":    [{ "name": "@zack/devwork-maintainer-state", "version": "0.1.0"  }],
  "profiles":  [{ "name": "@zack/devwork-maintainer-style", "version": "0.1.0"  }],
  "loop":      "@zack/devwork-triage-loop@0.1.0"
}

The four parts of Agent Package Management

A portable definition, a place to publish it, a way to install it and a way to run it. These are separate roles. AgentPM brings them together.

Defines

Standard

Specifies how Agent Packages and Components are described and interpreted, independently of a particular implementation.

APDS 1.0.0
Distributes

Registry

Makes versioned Agent Packages and reusable Components discoverable and available to other developers.

AgentPM Registry
Resolves & installs

Manager

Selects package versions, resolves dependencies and installs the composed system reproducibly.

AgentPM CLI
Executes

Runner

Interprets supported Agent Packages and executes their workflows. Other Runners can implement APDS independently.

AgentPM Harness

Start from where you are

Three ways in. No account needed to install.

Try one

install + run

Install a published Agent Package, then start it with the AgentPM Harness.

$ agentpm install @zack/devwork-copilot agentpm harness @zack/devwork-copilot

Running may require model configuration or credentials.

Build one

from scratch

Start a new Agent Package, then add Components and a Loop when you need them.

$ agentpm init

Start from a Template

whole workspace

Scaffold a project workspace from a published Template.

$ agentpm new @zack/support-assistant-workspace .
