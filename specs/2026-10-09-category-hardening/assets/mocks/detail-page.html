Execution architecture

How it runs, declared by devwork-triage-loop.

max 10 steps
  1. 1
    inspect-issue entry

    Decide whether there is enough evidence to draft a follow-up, or whether the work should hand off.

    Tools Knowledge Memory · read
    → draft-comment · handoff
  2. 2
    draft-comment

    Draft the next maintainer comment and capture follow-up notes that should survive this review pass.

    Tools Knowledge Memory · read + write
    → ready-for-resolution · needs-more-context
  3. 3
    resolve-or-handoff

    Decide the outcome. Tool access is withheld here, so the decision cannot take a write action on its own.

    Tools Knowledge Memory · read + write
    → resolve · revise-comment · handoff
