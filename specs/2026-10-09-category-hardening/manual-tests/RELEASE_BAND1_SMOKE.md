Run these commands locally, one block at a time. The publication commands create
real immutable versions in the production `zack` namespace. No provider/model
calls are needed. Retain their output and normal published URLs; never share a
token, passphrase or private signing key.

This first pass covers historical installs, compliant successors through both
protocols and fresh verified installs. Exact finalize retries and raw-client

import json
